# Data Insights Portal

A comprehensive financial data analytics platform that provides users with tools to manage transactions, budgets, goals, and gain insights through advanced analytics and forecasting.

## Features

- **Dashboard**: Visual overview of financial status with key metrics
- **Transaction Management**: Track and categorize financial transactions
- **Budget Management**: Create and monitor category-based budgets
- **Financial Goals**: Set and track progress toward financial objectives
- **Forecasting**: Predictive analytics for future financial scenarios
- **Financial Health Score**: Assessment of overall financial well-being
- **Reports**: Generate customized financial reports

## Technology Stack

- **Frontend**: React, Material-UI
- **State Management**: React Context API
- **Routing**: React Router
- **Charts**: Recharts
- **Backend**: Spring Boot API (Integration)
- **Database**: SQL Server & MongoDB
- **Authentication**: JWT
